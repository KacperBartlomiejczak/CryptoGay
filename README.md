# CryptoGay

Prosta aplikacja na Androida napisana w **Javie**, wyświetlająca kryptowaluty w 3 ekranach:
1. **Rynek (Market)** — lista kryptowalut z wyszukiwarką w czasie rzeczywistym.
2. **Ulubione (Favorites)** — podgląd ulubionych monet zapisywanych w lokalnej bazie SQLite (Room).
3. **Szczegóły (Details)** — wykres cenowy (MPAndroidChart), przedziały czasowe i kluczowe statystyki rynkowe.
